O que este modelo representa?

Este é um modelo fictício de aprendizagem, não uma previsão de epidemias reais. Monstros se movem ao acaso; contatos próximos podem transmitir. Máscaras e vacinas reduzem a chance no modelo, mas não garantem proteção. Vacinas não curam monstros já doentes. Recuperados ficam protegidos até o reinício. Os valores são inventados para explorar programação, probabilidade e variáveis.

Durante cada contato, a chance depende do tempo de proximidade. Máscaras multiplicam a taxa por 0,35 por usuário; a vacina multiplica por 0,15. Compare várias execuções: o acaso também muda os resultados. O cenário inicial usa sempre a mesma semente para facilitar comparações.
